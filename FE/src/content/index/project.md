# 临证首务·“综观四诊所获证象，大半均由问诊得来”

问诊是中医诊断的基础和核心，古人云：“综观四诊所获证象，大半均由问诊得来”。在中医诊断过程中，问诊占据了重要的地位，通过详细的询问患者的病史、症状、生活习惯等信息，医生能够全面了解患者的健康状况。

以往的问诊过程主要依赖于医生的经验和记忆，存在信息记录不完整、难以追踪和分析等问题。为了提升问诊的效率和准确性，我们开发了`灵·诊`的问诊功能，旨在为用户提供一个便捷、高效的在线问诊平台。

`灵·诊`的问诊功能通过自然语言大模型，结合中医诊断专业知识，可以根据用户情况实现针对不同方向的问诊，包括但不限于面诊、舌诊、情诊等。用户可以通过简单的文字输入，系统将自动分析用户的症状和病史，并提供个性化的健康建议和诊断结果。

问诊功能同时也可以与舌诊，面诊等其他诊断方式结合使用，形成一个综合的诊断体系，帮助用户更全面地了解自己的健康状况，并提供更准确的诊断结果和治疗建议。

并且，`灵·诊`的问诊功能还支持用户随时查看自己的健康记录和咨询历史，方便用户进行健康管理和跟踪。


## 使用指南

- 用户可以通过`灵·诊`平台的问诊功能，输入自己的症状和病史信息，系统将自动分析并提供个性化的健康建议和诊断结果。


- 用户可以通过附件上传的功能，将舌诊，面诊的诊断结果上传到系统中，系统可以结合这些信息进行综合分析，提供更准确的诊断结果和治疗建议。
